# Changelog

All notable changes to DMBTimer will be documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- WinUI 3 service countdown with timer, statistics, and settings pages.
- First-run wizard for profile, language, military branch, service term, notifications, and autostart.
- Calendar-year, fixed-day, and explicit end-date calculation modes.
- Built-in milestones, military branch holidays, and editable custom milestones.
- Windows notifications and selectable WAV notification sounds.
- Russian and English localization.
- Light and dark themes with animated transitions.
- System tray integration, Windows autostart, and keyboard shortcuts.
- Portable `.dmbbackup` export and restore with a round-trip smoke test.

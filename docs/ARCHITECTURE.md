# Architecture

## Overview

DMBTimer is a packaged WinUI 3 desktop application targeting .NET 8. The application uses MVVM for presentation state and keeps Windows-specific integration behind focused services or the window code-behind.

```text
App
 └─ MainWindow (WinUI shell and Windows integration)
     ├─ MainViewModel (screen state and commands)
     │   ├─ CountdownService
     │   ├─ MilestoneService
     │   ├─ MilitaryBranchService
     │   ├─ CustomMilestoneService
     │   ├─ MilestoneNotificationService
     │   ├─ SettingsService
     │   ├─ LocalizationService
     │   ├─ BackupService
     │   └─ AutoStartService
     ├─ NotificationService / NotificationSoundService
     ├─ GlobalHotkeyService
     └─ PageTransitionService
```

## Presentation layer

- `MainWindow.xaml` defines the timer, statistics, and settings views in one adaptive shell.
- `MainViewModel` exposes bindable state, `ObservableCollection` instances, and commands generated by CommunityToolkit.MVVM.
- `OnboardingViewModel` and `CustomMilestoneEditorViewModel` isolate dialog state and validation.
- Code-behind is limited to APIs that require a real WinUI window: file pickers, tray integration, keyboard accelerators, animations, and notification activation.

## Domain and application services

| Service | Responsibility |
| --- | --- |
| `CountdownService` | Calculates elapsed/remaining time and progress statistics |
| `MilestoneService` | Builds built-in, holiday, and user milestone timelines |
| `MilitaryBranchService` | Maps branches to localized names and fixed or movable holidays |
| `CustomMilestoneService` | Persists user-created stages |
| `MilestoneNotificationService` | Selects due notifications and prevents duplicates |
| `SettingsService` | Persists local application preferences |
| `LocalizationService` | Resolves `.resw` resources and culture-specific formatting |
| `BackupService` | Exports and restores versioned `.dmbbackup` archives |
| `AutoStartService` | Synchronizes the Windows startup entry with the UI |
| `GlobalHotkeyService` | Registers and handles the system-wide `Ctrl+D` shortcut |
| `PageTransitionService` | Animates navigation between application sections |

## Core flows

### Countdown refresh

1. `TimerService` triggers a periodic refresh.
2. `MainViewModel` asks `CountdownService` for current statistics.
3. Built-in and custom milestone collections are refreshed.
4. Due items are filtered by `MilestoneNotificationService`.
5. `MainWindow` shows an app notification and optionally plays the selected sound.

### First-run setup

1. The absence of the onboarding-completed setting opens the four-step wizard.
2. The wizard collects profile, language, military branch, service term, notification, and autostart preferences.
3. `MainViewModel` saves the profile and recalculates the real end date.
4. `MilitaryBranchService` adds the selected branch holiday to the timeline.

### Backup and restore

1. `MainViewModel` creates a versioned `AppBackup` model.
2. `BackupService` serializes the model and optional custom WAV into a `.dmbbackup` archive.
3. Import validates the archive before applying settings and milestones.
4. `BackupSmokeTest` verifies the export/restore round trip independently from the UI.

## Storage and privacy

Application settings use local Windows app storage. Custom milestones are stored as local application data. A backup leaves the device only when the user explicitly exports it through the Windows file picker. No network service or account is required.

## Extending the application

- Add UI text to both `DMBTimer/Strings/ru-RU/Resources.resw` and `DMBTimer/Strings/en-US/Resources.resw`.
- Add a military branch to `MilitaryBranch`, then define its localized name and holiday in `MilitaryBranchService`.
- Keep date calculations in services and expose presentation-ready values through view models.
- Add a backup migration before changing persisted model semantics.
